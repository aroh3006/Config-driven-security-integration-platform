What each fault shows

  • 503x3: three failures, retries at 1s, 2s and 4s, then success.
  • 503x4: one failure too many. The run is marked failed.
  • 429:30: rate limited, waits 30 seconds and carries on.
  • timeout: requests time out, retries run out and the run fails.
  • badrecord: one bad record goes to quarantine and the run continues.
